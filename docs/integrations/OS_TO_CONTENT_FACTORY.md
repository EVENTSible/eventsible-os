- Status: PLANNED

- Last verified: 2026-07-29
- Applies to: event-linked media/content workflow
- Supersedes: separate content-event database plans

Content Factory should be an OS module that uses the same OS `event_id` as the booking and planning workspace. It should support event-linked content jobs, draft generation, review-before-publish, scheduling, asset tracking, and post-event follow-up.

No content should publish automatically without human review.

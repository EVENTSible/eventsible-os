EVENTSible is a connected ecosystem with clear lanes:

| Lane | Purpose | Source of truth |
| --- | --- | --- |
| `eventsible.info` | Public website, service education, portfolio, reviews, and public planning entry | Public website / Builder docs |
| `build.eventsible.info` | Direct Event Builder production app | Event Builder repo |
| `eventsible.biz` | Private Business HQ, GigTracker, CRM, quotes, bookings, operations, staff, equipment, tasks, automation | EVENTSible OS repo |
| `client.eventsible.biz` | Booked-client planning workspace | EVENTSible OS / Client Portal |
| `eventsible.app` | ECC/VINCE live event platform | ECC/VINCE repo |
| `eventsible.shop` | Custom Creations storefront and production/order operations | Future shop lane |
| `www.eventsible574.com` | Legacy/local trust bridge | Legacy site |

## Operating Principles

- EVENTSible OS is the business system of record.
- ECC/VINCE is the live event-session system of record.
- Event Builder is a public capture and estimate experience that submits to OS.
- Client Portal reads and updates membership-scoped OS records.
- Content Factory remains an OS module using the same event IDs.
- Custom Creations can own product/order operations while referencing OS IDs when related to an event.
- No new feature is live until current source, deployment, and safe route/workflow evidence support it.
